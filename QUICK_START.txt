 ALTERNATIVAS SI APACHE NO FUNCIONA
═════════════════════════════════════════════════════════════════════════════

Si Apache no inicia desde XAMPP, intenta iniciar manualmente desde terminal:

Opción A (PowerShell como Administrator):
──────────────────────────────────────────
cd C:\xampp\apache\bin
.\httpd.exe -k start

Opción B (Instalar como servicio):
───────────────────────────────────
cd C:\xampp\apache\bin
.\httpd.exe -k install

Opción C (Reiniciar Apache):
─────────────────────────────
.\httpd.exe -k restart
